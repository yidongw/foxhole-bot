# journal/ — 每日明细日志

按类型分文件夹、按天分文件(`YYYY-MM-DD.md`),由代码自动追加,
是复盘和审计的明细层(根目录 `REVIEW-LOG.md` 是总结层)。

## filters/ — 过滤日志

每天暴涨扫描中**每一个币的判定明细**:留下的、过滤的、原因和指标
(涨幅/量/池/触发的过滤器),外加人工确认的最终决定。
用途:审计过滤质量 —— 错杀和漏放都能在这里看出来。

判定类型:
- **候选** — 通过全部自动过滤,等待人工确认
- **过滤** — 🪜 刷单画线 / 💀 无K线 / 🚨 安全标记(蜜罐、税、大户集中、黑名单)
- **标注** — 📉 已崩盘(仍作为学习案例,但不建议关注)
- **已报警** — 我们提前发过警报的(即成功案例)

## trades/ — 交易日志

机器人自己每一笔交易决策:开仓(价格、数量、触发信号)、平仓
(比例、原因、盈亏)、被安全门否决的入场。纸面和实盘同样记录。
